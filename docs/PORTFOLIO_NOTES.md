## Short Description

Roblox RPG prototype with magic combat, NPC patrols, shop upgrades, apple collection, boosters, static UI styling, and server-side cleanup.

## CV / Portfolio Bullets

- Built and cleaned a Roblox RPG prototype using Luau and Roblox Studio.
- Implemented server/client gameplay with `RemoteEvent` and `BindableEvent` communication.
- Developed a magic system with projectiles, cooldowns, mana costs, buildable spells, and a Super Magic area attack.
- Added NPC enemies with pathfinding patrols, detection radius, attack behavior, rewards, and respawn flow.
- Implemented shop upgrades, apple buy/sell logic, money/mana values, and basic DataStore persistence.
- Refactored duplicated booster logic into shared controller scripts.
- Moved UI styling into saved Roblox GUI properties so the interface is visible in Studio edit mode.
- Stabilized prototype bugs including unsafe loops, client-trusted economy values, inaccessible animation assets, and Studio DataStore warnings.
